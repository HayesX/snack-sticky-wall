# 零食便签墙 · 今天吃什么推荐器

![cover](assets/cover.png)

一个便签墙风格的零食推荐小工具：选择口味、场景与偏好，点击「帮我选」即可随机推荐一款零食，附带推荐理由与备选，还可浏览完整零食墙、查看单品详情。

## 在线 Demo

打开 https://HayesX.github.io/snack-sticky-wall/ 即可体验（GitHub Pages 首次部署可能需要 1-2 分钟）。

## 本地使用

直接用浏览器打开 `index.html` 即可，无需安装任何依赖，纯静态单文件应用。

## 功能

- 多维度筛选：口味、场景、热量、预算等
- 一键随机推荐 + 备选零食
- 零食详情弹窗
- 便签墙浏览全部零食

HTML / CSS / JS 单文件实现，数据内置。
